# Ядро террейна, этап 3: трава, деревья, стили картинки

Ветка `rework/terrain-core`. RTX 3070 Laptop, Vulkan, 1920×1080, headless, кадр ждёт GPU.
Мир: карта v5, 524 км, биомы «мира павших богов», старт в Дождливой речной долине (лес).

```
python tools/terrain_lab/build_foliage.py          # модели из new_assets -> assets/terrain_core/foliage (Blender в фоне)
python tools/terrain_lab/build_foliage.py --all    # все модели паков + лист миниатюр в .cache/foliage_thumbs
terrain_lab ... [--no-foliage] [--foliage-layers grass,conifers] [--no-ground]
```

## Как устроено

- **Модели:** 70 штук из `retro_nature_pack` (glb) и `tree_pack_1.1` (fbx), сконвертированы
  Blender'ом в простой бинарный `.mesh` (позиция, нормаль, UV) + текстура 256².
- **Слои** (`content/config/terrain_core/foliage.json`):

  | слой | шаг | дальность | модели |
  |---|---|---|---|
  | трава | 0.9 м | 70 м | пучки, 8 треугольников |
  | кусты мелкие | 3.5 м | 260 м | ~250 треугольников |
  | кусты крупные, осенние кусты | 9 м | 700 м | 16 треугольников |
  | молодые деревья | 10 м | 400 м | ~330 треугольников |
  | хвойные, лиственные, осенние | 7–9 м | 3.5 км | карточки, 52 треугольника |

- **Плотность по биомам:** у каждого биома для каждого слоя плотность, размер пятен-кластеров
  (леса растут массивами) и доля покрытия.
- **Каждый кадр с нуля, без стриминга и состояния:** compute-шейдер проходит по сетке клеток
  каждого слоя. Позиция внутри клетки — хеш целочисленной клетки мира, поэтому дерево всегда
  стоит на том же месте.
- **Порядок отбраковки, от дешёвых проверок к дорогим:**
  1. дальность;
  2. фрустум по вертикальному отрезку — ещё до чтения текстур;
  3. склон и море;
  4. биом — та же функция `biome_pick.hlsli`, что красит землю, поэтому лес кончается там же,
     где его земля;
  5. правила слоя и кластеры;
  6. фрустум по сфере экземпляра;
  7. размер на экране меньше 1.5 пикселя.
- **Отрисовка:** выжившие экземпляры атомиками дописываются в срез буфера своей модели, затем
  **один** `DrawIndexedPrimitivesIndirect` на все 70 моделей.
- **Край дальности:** к концу дальности плотность падает, а растения «вырастают» из земли.
  Поэтому края нет.

3.3 млн треугольников из 4.2. Вынесены в свой слой на 400 м: кадр 2.7 → 2.3 мс.

## Поправка: фолиаж — это трава

Деревья и кусты выше — отдельный модуль **деревья** (F3, `--no-trees`). Фолиаж — это
**сплошная трава** там, где земля окрашена травяным материалом, в цвет земли
(`terrain_core::Grass`, `grass_spawn.hlsl`, `grass_draw.hlsl`).

- **Где растёт:** у каждого материала земли есть «травяность» (по умолчанию все `grass_*`
  = 1, в `biomes.json` можно задать `"grass": 0..1`). Проба земли — та же функция
  `ground.hlsli`, что красит землю, теперь работает и в compute — отдаёт цвет и количество
  травы в точке.
- **Как покрывает:** пять колец вокруг камеры (8, 16, 32, 64, 128 м). Шаг каждого кольца
  вдвое крупнее, пучки вдвое шире, но не выше, поэтому покров везде сплошной, а пучков в
  каждом кольце одинаково. Кольцо — фиксированная сетка мира, трава не «плывёт». Соседние
  кольца перекрываются и меняются размером.
- **Цвет:** пучок берёт освещённый цвет земли под собой; спрайт Kenney (белый, с градиентом)
  только тенит его. В среднем пучок ровно такой же яркости, как земля, а затенение у корня с
  расстоянием уходит. Там, где кончаются пучки, дальше идёт земля того же цвета — края не
  видно. Сверху пучки ложатся (иначе карточки ребром выглядят царапинами).
- **Спрайты:** `tools/terrain_lab/build_grass.py` — 14 пучков и 4 с цветами из
  `kenney_foliageSprites`.

## Стили картинки (F5, `--post 0..3`)

1. **Дарк фэнтези:** обесцвечено, тяжёлые придавленные тени, холодный низ, тусклый тёплый
   верх, зерно, виньетка.
2. **Фразетта:** мазок (фильтр Кувахары r=4), землистая палитра умбра → охра → тёплый свет,
   резкая светотень, края уходят в тёмно-коричневое, фактура холста.
3. **Вальехо:** «аэрограф» (мягкая Кувахара + размытие), насыщенно, сине-фиолетовые тени,
   тёплые глянцевые светá, свечение ярких мест.

Пост-эффект пишет результат обратно в кадр, поэтому окно и снимки видят уже стилизованную
картинку. Полутоновый дизеринг убирает ступени в градиентах.

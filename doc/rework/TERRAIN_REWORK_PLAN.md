# Реворк террейна: план

Ветка `rework/terrain-core`, отправная точка — снапшот `e8c0cf8`.

Задача: перестать лечить симптомы старого террейна (страницы, атласы, CPU-меши,
запечённые материалы) и собрать ядро заново, **с замерами на каждом шаге**.
Старый код не трогаем, пока новый не догонит его по функциональности: новое ядро
живёт отдельно (`src/terrain_core/` + исполняемый `terrain_lab`) и зависит только
от `engine::Device` (SDL3 GPU + компиляция HLSL), SDL3 и shadercross.

## Требования

- Мир до **2000 × 2000 км**. Подгрузка бесшовная, как в Minecraft: никаких дыр,
  видимых «появлений» чанков, фризов при движении.
- Меша на CPU нет. Высоты лежат в GPU-текстурах, сетку поднимает вершинный шейдер.
- Источник высот один из двух, с одинаковым дальнейшим путём:
  - импорт: 16-битная карта высот (например, `doc/NewRef/world_heightmap_v5_4096_gray16.png`),
    растянутая на размер мира;
  - генератор: рисует такую же карту высот и пишет её в тот же формат.
- Детализация ниже разрешения макрокарты (на 2000 км один тексель 4096² — это 488 м)
  достраивается процедурно на GPU, детерминированно.

## Архитектура ядра (этап 1)

**Высоты: макрокарта + процедурная детализация.**
`h(x, y) = macro(x, y) + detail(x, y)`. Макрокарта — R16 текстура на весь мир
(бикубическая выборка). Детализация — сумма октав шума, амплитуда модулируется
макрорельефом (горы шероховатые, равнины гладкие). Октава с длиной волны λ
пишется только в уровни, где λ ≥ 2 × шаг уровня: грубый уровень — это
отфильтрованная версия тонкого, поэтому при смене LOD рельеф не «прыгает».

**Точность на 2000 км.** float32 на 2·10⁶ м даёт шаг ~0.25 м — мало. Поэтому:
позиции на CPU в double / int64; на GPU всё относительно камеры; шум считается от
**целочисленных** координат текселя уровня (решётка октавы — целое деление), а не от
float-координаты мира. Результат одинаков в начале координат и на краю мира.

**Данные: клипмап.** L уровней, каждый N×N текселей, шаг уровня `s·2^l`, адресация
тороидальная (Texture2DArray, слой = уровень). Камера сдвинулась на тексель уровня —
compute-шейдер дописывает полосу шириной в этот сдвиг. Всё, что видно, всегда
покрыто хотя бы грубым уровнем, поэтому дыр не бывает в принципе. Телепорт —
полная перегенерация L·N² текселей (её время тоже мерим).
Хранится: высота (R32F) и нормаль (RG16F/RG8), считаются в той же генерации.

**Геометрия: CDLOD поверх клипмапа.** Квадродерево узлов по всему миру (глубина
~15–17 для 2000 км), выбор узлов по дистанции и фрустуму на CPU — это сотни узлов,
не мегабайты. Каждый узел рисуется одной и той же сеткой G×G вершин (один
инстансный draw на всё). У границы LOD вершины морфятся к сетке родителя —
трещин и T-стыков нет, переход плавный. Узел уровня l читает высоты из уровня
клипмапа l (шаги совпадают).

**Шейдеры.** Только свои, минимальные: VS (выборка высоты + морф), FS (ламберт по
нормали + цвет по высоте/склону + туман на горизонте). Никакого неба, постобработки,
теней, материалов — они не должны влиять на замеры.

## Этапы

### Этап 0 — подготовка ✅
- [x] Снапшот текущего состояния, ветка `rework/terrain-core`.
- [x] Изолированный модуль `src/terrain_core/` и исполняемый `terrain_lab`
      (окно + headless), свободная камера, HUD с цифрами.
- [x] Бенч-режим: скриптовые пролёты, CSV/JSON с метриками, отчёт в
      `doc/reports/terrain_core/`.
- [x] GPU-время по проходам через `tools/gpu_profile.py` (Vulkan-слой
      `campfire_gpu_layer`, у SDL3 GPU своих таймстемпов нет).

### Этап 1 — высоты и стриминг ✅ (отчёт: `doc/reports/terrain_core/step1/README.md`)
1. Макрокарта: импорт PNG16 → R16 текстура мира; генератор → тот же формат.
2. Клипмап + compute-генерация полос + тороидальная адресация.
3. CDLOD-выбор узлов, морфинг, один инстансный draw.
4. **Матрица замеров** (см. ниже) → выбор шага, N, G, L.

Итог: базовый пресет — шаг 0.5 м, N 256, G 32, 11 уровней (~41 км), кадр
0.3–0.45 мс при 1080p, отставаний стриминга 0 до 3000 м/с. Хвосты этапа 1:
дальний слой из макрокарты за пределами клипмапа; CPU-функция высоты для
геймплея; живой облёт для оценки морфа.

### Этап 2 — биомы и материалы ✅ (отчёт: `doc/reports/terrain_core/step2/README.md`)

Итог: карта биомов (импорт раскладки «мира павших богов» или генератор), 31 материал из
`Free.zip`, островки, склоны, высота, рваные границы, антитайлинг, антиалиасинг шума.
Кадр 0.73 мс пешком / 0.95 мс в полёте при 1080p (террейн на GPU 0.43 / 0.68 мс).

- Биом-карта (импорт или генератор) того же масштаба, что и макрокарта.
- Шейдер: биом → набор материалов; шумовые «островки» внутри биома; материал по
  склону (slope worker); смешение границ биомов (шум + высота/вес).
- Текстуры из `new_assets` (Free PBR: Dirt/Grass/Rock/…, RG Retro Nature, Kenney
  retro textures) → Texture2DArray с мипами.
- Замеры: стоимость FS на пиксель, число выборок, влияние на кадр.

### Этап 3 — фолиаж на GPU
- Размещение целиком на GPU: compute по клеткам вокруг камеры, плотность от биома,
  склона, высоты; детерминированный хеш от целочисленной клетки мира.
- Отсечение: фрустум + Hi-Z окклюзия + дистанция; LOD (меш → карточка/импостор).
- Indirect draw, ни одного CPU-цикла по инстансам.
- Ассеты: `retro_nature_pack`, `tree_pack_1.1` (FBX), `kenney_foliageSprites`.
- Замеры: инстансов в кадре, стоимость cull/draw, overdraw.

## Матрица замеров этапа 1

| Параметр | Значения |
|---|---|
| Размер мира | 16 км, 256 км, 2000 км (и позиция у края мира, ≈1.9·10⁶ м) |
| Шаг s (уровень 0) | 0.25, 0.5, 1, 2 м |
| Клипмап N | 128, 256, 512 |
| Сетка узла G | 16, 32, 64 |
| Уровни L | от дальности видимости: 8, 16, 32 км |

Сценарии: стоим на месте; пешком 5 м/с; бег/конь 20 м/с; полёт 300 м/с;
«самолёт» 3000 м/с; набор высоты 2 м → 20 км; телепорт через полмира.

Метрики: GPU мс кадра (генерация / террейн), CPU мс (выбор узлов, запись команд),
треугольников и вершин в кадре, текселей перегенерировано за кадр, задержка
стриминга (кадров, на которые какой-либо уровень отстал от камеры — цель 0),
максимальная скорость без отставания, время телепорта, VRAM.

Критерий «бесшовно»: при целевой скорости ни один уровень не отстаёт ни на кадр,
а p99 кадра не выше бюджета (16.6 мс при 60 fps на RTX 3070 Laptop, с запасом
под этапы 2–3 — террейн целимся ≤ 2 мс GPU).

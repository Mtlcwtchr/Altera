# Генератор мира по правилам — план

10 октября 2026. Ветка `rework/terrain-core`. Основа — биомы `doc/BIOMES_RU.md`.

## Что строим

Генератор берёт **правила** (`content/config/terrain_core/world_rules.json`) и строит мир заданного
размера: карту высот, карту биомов, каркас воды (основные реки и озёра), карту осадков и линии
клифов для мешей. Всё в пределах мира: по краям — океан, обрывов на границе нет.

Сид меняет формы и размеры. Топологию — кто с кем граничит и чем — держат правила.

## Основной материк (правила для этой игры)

Мир 524 км, материк ~70%. Север сверху.

```
                 северный океан
        ~  СЕВЕРНЫЕ ОСТРОВА (наклонные плато, Исландия)  ~
   ~~~~~~~~~~~~~~ чёрный берег ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
   |  ЧЁРНЫЕ ПИКИ — иссохшие, острые, клифы к долине         |
   |=== речная долина (узкая, река на запад, к морю) ========|
 м |  БЕЛЫЕ ГОРЫ — хребет; в нём круглая долина с озером (O)  | м
 о |  предгорья-холмы        |  тёмный лес до предгорий      | о
 р |  ПЛАТО: холмистые        |  МАРШИ → речные марши,       | р
 е |  равнины                 |  дельты (единственные)       | е
   |  >>> острый клиф (нависающий) к степи <<<               |
   |  каньон по кругу; СТЕПЬ, каменистые каньоны, шпили      |
   |  ПУСТЫНЯ — обширная, дюны                               |
   ~~~~~~~ клифовый берег, ровный, как срезанный ~~~~~~~~~~~~~~~
                 южный океан
```

Связи и переходы:

| От | К | Переход |
|---|---|---|
| океан | пустыня | резкий клиф, ровный верх, «срезанный» |
| пустыня | степь | плавно: дюны → каменистая пустыня → степь |
| степь | всё вокруг | степь всегда окружена резким каньоном |
| степь | плато | острейший клиф под острым углом (нависание → меш) |
| плато | марши | плавный спуск: холмы → низины → марши → речные марши у моря |
| марши | тёмный лес | лес на суше выше маршей |
| тёмный лес | белые горы | лес поднимается на пригорья, не выше |
| плато | белые горы | холмистые пригорья |
| белые горы | речная долина | склоны хребта |
| речная долина | чёрные пики | резкие клифы и горы со стороны долины |
| чёрные пики | океан | чёрный берег |

Вода:

| Зона | Сток, осадки | Реки |
|---|---|---|
| пустыня, степь | 0 | нет |
| плато, равнины | мало | небольшие реки с гор |
| марши | много | речные марши = дельты, единственные в мире |
| тёмный лес | много | ручьи |
| белые горы | много (снег) | ручьи в долину с озером, ручьи в речную долину |
| круглая долина | — | большое озеро в центре |
| речная долина | много | одна главная река, питается горными ручьями |
| чёрные пики | 0 (иссохшие) | нет |

Рельеф: основной рельеф — шум и **термальная** эрозия (крупномасштабная, на возвышенностях:
срезанные пики, осыпи, угол откоса — красивые возвышенности, а не гладкие «сиськи»).
**Речная** эрозия везде слабая и сглаженная, **кроме каменных степей**: там она режет глубокие
каньоны, которые меш-часть гибрида доводит до отвесов, выступов и шпилей.

## Этапы

1. **Правила и раскладка.** Формат правил. Маска материка с океаном по краям. Зоны в полосах по
   оси юг–север с изрезанными (warp) границами, боковые зоны (марши, лес — восток). Северные
   острова. Результат — карта зон (биомов) и превью.
2. **Рельеф по зонам и переходам.** Рецепт каждой зоны:
   - дюны;
   - каменистые каньоны со шпилями;
   - кольцевой каньон;
   - плато с ножевым клифом;
   - холмы;
   - низины маршей;
   - хребты;
   - круглая долина;
   - узкая долина;
   - острые иссохшие пики;
   - наклонные плато островов.

   Переходы на границах по правилам (клиф, каньон, плавный спуск, пригорья). Берега по типам:
   срезанный клиф, чёрный берег, дельты.
3. **Эрозия по правилам.**
   - Термальная — основная, по всем возвышенностям.
   - Речная везде слабая и сглаженная; сильная (глубокие каньоны) только в каменных степях.
   - Клифы не размываются.
4. **Вода по правилам.**
   - Карта осадков по зонам: сток в пустыне и степи нулевой.
   - Каркас: главная река долины, озеро в кольце гор, реки с гор на равнины, дельты только в
     речных маршах.
   - Гидрология (каркас + притоки) строится на этом.
5. **Клифы-меши.** Острые и нависающие клифы (край плато над степью, срезанный берег, чёрные пики)
   — гибрид: карта высот плюс меш-стенки вдоль линий клифов.
6. **Материалы и растительность** по зонам — таблица биомов уже есть, подключить.

На каждом этапе — превью и проверка в terrain_lab.

Вода по правилам: генератор пишет `world_water.png` (R — сток зоны, G — где разрешены дельты,
B — грунт, который поглощает воду: пустыня, степь, чёрные земли). Лаборатория читает его флагом
`--water-rules`. В сухих зонах нет рек и озёр, реки с плато доходят до их границы и
заканчиваются. Дельты только в речных маршах (в том числе на востоке долины). Главная река долины
течёт на восток.

# Карточки модулей

Одна карточка = один модуль, 15–30 строк. Открывать карточку вместо поиска по коду; дальше `Grep` по `doc/INDEX.md` и точечное чтение диапазонов строк.
Формат: Назначение / Где / Тесты и запуск / Подводные камни / Спеки. Метка **[сверить]** — написано облаком по спекам, ПК-сессия проверяет по коду при первой правке и снимает метку.
Индекс файлов: `python tools/gen_index.py` (пересобирает `doc/INDEX.md` из шапок файлов). Проверка контента: `python tools/validate_content.py`.

Модули: sim, ai, crafting, interactions, combat, terrain_core, world_view, ui, loc.

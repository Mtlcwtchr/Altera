# world_view — сцена мира в клиенте (в разработке)
Назначение: `altera_world_view` — бывший `Lab` без CLI: загрузка мира и порядок проходов кадра как общий слой для лабы и игры (слияние).
Где: целевая схема `engine_merge/MERGE_PLAN.md`; клиент `src/game/client`, рендер `src/game/render`, движок `src/engine/render` (старый RTS-стек уходит в legacy, затем удаляется).
Состояние: план v0.1 (18.11); код слияния в очереди ПК после ядра боя. Клиент сейчас: HUD по макету, модели UAL, групповые бои/плен/казнь.
Запуск: `altera_client.exe`; для проверок без окна планируется флаг `--smoke N` (SPEEDUP_PLAN A5).
Подводные камни:
- Один рендер на игру и лабу: не плодить копий проходов; PSX-фильтр встаёт последним.
- Форматы `campfire.*` принадлежат движку Campfire (отдельный проект), в Altera не переименовывать.
- Сим не должен включать заголовки рендера (`altera_sim` независим).
Спеки: `engine_merge/MERGE_PLAN.md`, `psx_postfx/`.

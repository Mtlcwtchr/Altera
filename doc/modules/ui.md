# ui — HUD, меню и колесо взаимодействий
Назначение: интерфейс как в Sims, но средневековый: панель нужд/настроения, колесо→дерево влияния в диалоге, доски крафта, колония top-down.
Где: `src/game/client` **[сверить]**; дизайн: канвас «Altera UI и HUD» (палитра, макеты), скриншоты `tour_*.png` в файлах проекта.
Запуск: `altera_client.exe`; кадры снимать только по просьбе пользователя.
Подводные камни:
- Палитра уходит от охры к «Sims + средневековье»; решения пользователя по UI в памяти проекта (`ui-design`).
- Все тексты через loc-ключи, без литералов; русские падежи/род — через `Loc::formatLoc`.
- Доски крафта: часть не решена (`ui-crafting-boards` в памяти).

# Старые таблицы каменного века (content/resources, content/items, content/recipes)

Живой сим их **не читает**. Сим берёт данные из `content/ai`: objects.json и items.json, пакеты cuisine, expansion и resources, крафт без рецептов в `content/ai/craft`. Эти файлы остались от первой версии игры (каменный век, бронза, Месопотамия) и лежат здесь как справочник.

Решение по эпику AL-86 (24.11): оставить файлы и адаптировать то, что подходит средневековью.

- **Перенесено** в пакет `content/ai/resources` (источник: `tools/content_gen/gen_resources.py`):
  - тысячелистник: трава от ран, объект yarrow_patch;
  - дикий лён (wild_hemp), медная жила (copper_vein), дуб с корой (oak_tree).
- **Уже было** в живом симе: камыш (reed_bed), глина, хворост, ягоды, ива.
- **Медь и олово:** медная руда добывается, олово (tin_vein) не переносилось. По решению пользователя олово приходит только торговлей.
- **Бронза:** сплав `alloy_bronze` есть в `content/ai/craft/reacts.json`. Рецепты литья из bronze.json заменяет крафт без рецептов.
- **Не переносилось (не средневековая Европа):** финиковая пальма, тамариск, полба, эммер, сырцовый кирпич, глиняный серп.
- **Отложено как идеи:** войлок и войлочный плащ, праща, бурдюк, жаропонижающий отвар (частично его закрывает липовый чай).
